# Sales Overview

SAP Fiori **Overview Page** for Helvetia Motion AG. Mock SD data follows the document flow quotation → sales order → delivery → billing → accounting document.

## Run locally

```bash
npm install
npm start
```

Opens [http://localhost:8083/index.html](http://localhost:8083/index.html).

```bash
npm run generate-mockdata
npm run check-document-flow
```
